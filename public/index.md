## Introduction
I build systems that help software do more. Eshan Roy (`eshanized`) builds systems software, developer infrastructure, and open-source operating systems.

## Engineering Pipeline
- **Concept**: Define the boundary of the problem worth solving.
- **Architecture**: Structure module hierarchy, data flow, and failure modes.
- **Implementation**: Strict typed interfaces with no perimeter bypasses.
- **Verification**: Clean compiler passes, clean sandbox tests, and cryptographic SHA-256 evidence digests.
- **Release**: Open source with transparent status and comprehensive documentation.

## Flagship Systems
- **M31A**: Autonomous coding-agent runtime with deterministic 11-stage policy gates and atomic SQLite WAL commits (https://m31a.tonmoyinfrastructure.org).

- **MCP SuperAssistant**: Developer tooling for the Model Context Protocol ecosystem.
